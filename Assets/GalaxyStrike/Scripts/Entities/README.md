# Entities 面向对象实体层 · 架构说明与 AI 规范

> **所属命名空间**：`GalaxyStrike.Entities`  
> **设计定位**：封装玩家战机、多态敌机集群、多样化弹道及战术掉落物资的纯 C# 面向对象实体体系。

---

## 类继承树与多态分发结构

```
Entity (抽象基类: 封装 AABB 碰撞盒、基础移动、活动生命状态)
├── Player (玩家主力战机: 5阶机体形态演进、5阶火力弹道、脱战护盾自愈、双层环微型分叉全屏核弹)
├── Bullet (高能等离子/贯穿激光/追踪飞弹/环形弹/螺旋弹)
├── PowerUp (战术掉落物资: P火力 / U升阶经验 / S护盾补充 / B全屏核弹 / $战况积分)
└── Enemy (敌机二级抽象基类: 封装掉落几率、受创闪烁、虚方法 UpdateBehavior / Shoot)
    ├── ScoutEnemy (蜂群侦察机: 3种冲锋编队轨迹，高机动直线下冲)
    ├── GunshipEnemy (定高巡航炮艇: 保持安全巡航射击窗口，双联机炮瞄准)
    ├── BomberEnemy (重装轰炸机: 高装甲大碰撞体，缓慢下压并抛射散射重弹)
    ├── EliteCruiser (精英巡洋舰: 正弦波悬停蛇形机动，双向螺旋穿插弹幕)
    └── BossEnemy (灭世星际母舰: 三阶段狂暴演进，多弹种混编全屏压制)
```

## 核心数值与平衡参数表

### 1. 战机进阶形态 (Player Evolution)
经验升级公式：$$\text{ExpNext} = \text{Exp} \times 2 + 30$$
* **Lv.1 Falcon-I**：HP 100, 护盾 50, 速度 32
* **Lv.2 Viper-II**：HP 140, 护盾 80, 速度 34 (需要 50 EXP)
* **Lv.3 Phoenix-III**：HP 190, 护盾 120, 速度 35 (需要 130 EXP)
* **Lv.4 Thunder-IV**：HP 250, 护盾 170, 速度 36 (需要 290 EXP)
* **Lv.5 Hyperion-V**：HP 320, 护盾 240, 速度 38 (需要 610 EXP)
* **护盾脱战自充**：脱战 3 秒后，每秒自动回复 15 点护盾。

### 2. 武器火力弹道模式 (Weapon Tiers)
* **Lv.1 单发高能等离子 (Single Plasma)**：直射等离子弹，伤害 15
* **Lv.2 双联装极速光束 (Twin Blaster)**：对称双通道，单发伤害 16
* **Lv.3 三向散射重炮 (Triple Spread)**：中央直射 + 左右两侧扩散，伤害 18/16
* **Lv.4 贯穿死光阵列 (Piercing Beam)**：极速贯穿激光束，单发高伤 22
* **Lv.5 歼星齐射+追踪飞弹 (Omni Annihilator)**：贯穿激光 + 2枚自动导引飞弹，总伤爆表

### 3. 敌机灭世母舰三阶段演进 (Boss Phases)
* **Phase 1 (HP > 60%)**：主炮蓄能双向交火，周期性向下推进扫荡；
* **Phase 2 (25% < HP <= 60%)**：主炮过载，高频三联重炮 + 侧翼散射；
* **Phase 3 (HP <= 25%)**：狂暴状态，持续喷涌超密度螺旋能量风暴。

## AI Agent 开发规范与注意事项

1. **开闭原则 (OCP)**：
   * 增加新机型直接继承 `Enemy` 并实现虚方法，严禁在 `GalaxyStrikeGame` 的主循环里堆砌 `switch-case`。
2. **伤害判定封装**：
   * 伤害扣除与受击反应必须通过 `Entity.TakeDamage()`，外部严禁直接篡改内部血量字段。
3. **掉落物资磁吸**：
   * 距离战机 16 码内触发强向心磁吸加速（22 格/秒），超出 16 码时维持正弦波慢速漂浮。
