### 1. 战术边框细节 (`DrawCombatViewportFrame`)
* **双层防爆光线**：外圈半透明青蓝防护线 (`rgba(0, 240, 255, 0.4)`)，内圈 $0.5\text{px}$ 科技发光描边；
* **四角战术角标**：四个顶点绘制 $16 \times 16\text{px}$ 的加粗切角瞄准括号；
* **顶部状态胶囊**：显示 `COMBAT ZONE // SECTOR-01 · ORBIT: LOW-EARTH`；
* **左右高度刻度**：交火区两侧按比例渲染 5 组高度与引力标尺刻度线。

### 2. 标题菜单与交互按钮 (`DrawTitleScreen` / `DrawHeroButton`)
* **背景底图**：通过 `Resources.Load<Texture2D>("GalaxyStrikeArt/Sprites/TitleBackground")` 渲染 1080P 卡通科幻原画；
* **Hero Action 按钮**：双层切角赛博按钮，带金黄渐变投影（`#FFD000` 到 `#FF9E00`）、悬停高亮发光与动态边框扫光效果。

## AI Agent 开发规范与注意事项

1. **响应式自适应**：
   * 所有坐标计算必须基于 `Screen.width` 和 `Screen.height` 的相对百分比，严禁绝对像素硬编码导致在 4K 或移动端变形。
2. **GUI 状态压栈与恢复**：
   * 在修改 `GUI.color` 或 `GUI.backgroundColor` 时，方法退出前必须还原原始值：
     ```csharp
     Color oldCol = GUI.color;
     // ... 绘制逻辑 ...
     GUI.color = oldCol;
     ```
3. **性能保护**：
   * 纯色材质与背景纹理使用单例缓存，严禁在 `OnGUI()` 每次调用时 `new Texture2D()`，防止显存与堆内存泄漏。
